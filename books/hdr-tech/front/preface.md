# 前言

HDR 的工程实现由三件事支撑：一条能描述绝对亮度的传递函数，一套能把创作意图带到显示端的元数据，以及一个能在自身能力范围内完成映射的显示系统。这本分册围绕这三件事展开，同时把镜头往后拉到编码传输、实时渲染、移动端与 Web、影院直播广播，以及 SDR 与 HDR 长期共存这几处工程现场。

内容从人眼的对比敏感度与动态范围讲起，随后进入 PQ 与 HLG 的数学细节、元数据与码流封装、色调映射与逆映射、显示硬件的限制与测量评价，再讨论 10 bit 链路上的编码传输、游戏与实时渲染的管线、移动端与 Web 的落地方式、影院与广播的做法，最后回到标准化现状和几个还没有定论的问题。

公式会给出必要的推导与参数，图示均基于公开标准或可复现的计算。读者不必事先熟悉 HDR，但如果对亮度与动态范围的基本概念还不清楚，建议先补齐这部分常识再进入推导。
