## 1. ProbeCheck《显示器 HDR 测试：你的屏幕支持 HDR 吗？》

**链接**：https://probecheck.com/zh/guides/monitor-hdr-test

**为什么要测 HDR 支持**：HDR 能显著提升游戏/电影/创作画质，但前提是显示器真支持；很多显示器标称 HDR，亮度与色彩却不够，体验有限。

**HDR vs SDR（文中对比表）**

| 特性 | SDR | HDR |
|---|---|---|
| 峰值亮度 | 250–350 nit | 400–1600+ nit |
| 色深 | 8bit（1670 万色） | 10bit / 12bit（10 亿+色） |
| 色域 | sRGB | Display P3 / Rec.2020 |
| 对比度 | 1000:1（典型 IPS） | 视情况（分区背光更高） |
| 元数据 | 无 | 静态（HDR10）或动态（HDR10+/杜比视界） |

**四种 HDR 格式**

| 格式 | 类型 | 说明 |
|---|---|---|
| HDR10 | 静态元数据 | 通用标准，所有 HDR 显示器支持 |
| HDR10+ | 动态元数据 | 逐帧亮度调整，三星主推 |
| 杜比视界 | 动态元数据 | 需授权，支持 12bit |
| HLG | 基于场景 | 广播电视（BBC、NHK） |

**在线测试原理**：浏览器通过 CSS 媒体查询判断设备能力——`dynamic-range: high` 判断 HDR 支持、`color-gamut: p3` 判断广色域，另可检测色深（8/10bit）、分辨率、像素密度、坏点。注意：HDR 检测需显示器 OSD、显卡驱动、操作系统、浏览器**每一层都开启 HDR**，任何一层缺失都会报告 SDR。

**色深含义**：8bit = 仅 SDR（1670 万色）；10bit = 支持 HDR（10.7 亿色，HDR10 与杜比视界最低要求）；12bit = 高级 HDR（680 亿色，完整杜比视界所需，消费级少见）。

**色域覆盖**：sRGB 约占 CIE 1931 色域 35%；Display P3 约 45%；Rec.2020 约 75%（目前很少完全覆盖）。

**DisplayHDR 认证（文中列出）**：DisplayHDR 400（400 nit，入门）；500（入门可接受）；600（良好 + 分区背光，推荐最低标准）；1000（出色 + 深邃黑色）；1400（顶级，接近 OLED）。低于 400 nit 的 HDR 效果有限。

**各平台设置**（文中示例为 Windows 11）：设置 > 显示 > HDR，开启“使用 HDR”；调“SDR 内容亮度”滑块；游戏开启“Auto HDR”；再运行画面测试验证。

**如何选购 HDR 显示器（文中建议）**：亮度 600+ nit（DisplayHDR 600）；分区背光 FALD 或 mini-LED；色深 10bit（8bit+FRC 可接受但非真 10bit）；色域 90%+ DCI-P3；对比度 1000:1+（IPS）、3000:1+（VA）、无限（OLED）。面板对比：OLED 优秀、Mini-LED 很好、VA(FALD) 良好、IPS(FALD) 良好、IPS(侧入式) 差、VA(侧入式) 差。

**常见问题**：HDR 支持依赖全链路开启；HDR10 是内容格式、DisplayHDR 是 VESA 显示器认证，二者不同；HDMI 与 DP 都支持 HDR（HDMI 2.0 支持 4K60 HDR10，HDMI 2.1 增加 HDR10+ 与 4K120，DP 1.4 支持 4K60 HDR10，DP 2.0 支持 4K120 HDR）；日常办公通常 SDR 更好，Windows 11 的 Auto HDR 可智能切换。流媒体 4K HDR 建议 25+ Mbps。

## 2. 微软支持《使用 Windows HDR 校准应用校准 HDR 显示器》

**链接**：https://support.microsoft.com/zh-cn/windows/hardware/display-graphics/calibrate-your-hdr-display-using-the-windows-hdr-calibration-app

**作用**：校准 HDR 显示器，提高颜色准确性与一致性；可自定义开启 HDR 时 SDR 内容的显示方式。应用可从 Microsoft Store 下载（Windows 11）。

**三种测试模式（HDR 游戏兴趣组 HGIG 推荐）**，用于确定：
- 显示器的最大亮度；
- 最小亮度、最大帧平均亮度（拖动滑块直到测试图案刚好不再显示）。

**使用要求与步骤**：
- 需要支持 HDR 的显示器（内置或外接）；
- 先在“显示 HDR > HDR 视频”中打开 HDR；确认显示器“支持 HDR 视频流、游戏、应用”；
- 若有多台显示器，确保“Windows HDR 校准”窗口在支持 HDR 的那台上；
- 拖动滑块校准三种测试模式，直到每个测试图案不再显示；
- 可用“饱和度”滑块调整 SDR/HDR 内容颜色饱和度（变化可能很微妙）。

**注意事项**：
- 经过 HDR 认证的显示器通常开箱即用，但仍建议用本应用校准；
- 若显示器默认启用后处理效果，可能影响校准，可经 OSD 关闭；
- 在校准常用的相同光照条件下使用应用；
- 饱和度不要调太高，否则 HDR 内容会显得不自然/过饱和；
- 生成的**颜色配置文件（ICC）**可在“控制面板 > 颜色管理”中删除。

## 3. 知乎《先别玩显示器了，快来了解下 HDR 的基本知识吧！》

**链接**：https://www.zhihu.com/tardis/zm/art/376751931 （作者：毅种循环）

**HDR 是什么**：High Dynamic Range，高动态范围；在影像领域扩展亮度范围，呈现更多内容、更丰富色彩与更自然细节，让画面更接近人眼所见。摄影 HDR（多张不同曝光合成）与显示 HDR 是不同概念。

**人眼 vs 显示设备**：人眼可感受约 0.001–1000000 nit 的亮度范围，瞬时对比度可达约 10000:1；主流液晶普遍 300–400 nit、对比度约 2000:1，远低于人眼。HDR 就是要扩展显示亮度范围，让亮更亮、黑更黑。

**动态范围/色深**：传统设备 8bit，即 RGB 各 256 级明暗（1677 万色）；专业软件已支持更高位深处理，为屏幕预留了动态范围冗余。

**硬件与带宽**：曾提到 UHD Premium 认证指标——3840×2160、10bit、BT.2020 输入、显示再现超出 90% P3、HDR、SMPTE ST 2084 EOTF，以及两档亮度/黑位组合之一（>1000 nit 峰值且 <0.05 nit 黑位，或 >540 nit 峰值且 <0.0005 nit 黑位）。HDMI 2.0a 及以上才能传 HDR 元数据，DisplayPort 1.4 起满足要求。

**四大标准**：HDR10（开放、最常见、静态元数据）；杜比视界（动态元数据、逐帧适配、需授权）；HDR10+（三星、动态元数据、免版税）；DisplayHDR（VESA 的 PC 显示器认证，HDR400/600/1000 等）。

**DisplayHDR 分级（文中细节）**：
- DisplayHDR 400：真 8bit、全局调光、400 nit、约 95% sRGB；
- DisplayHDR 500：500 nit、广色域、8bit+FRC（抖 10bit）即可、**要求全阵列局部调光**；
- DisplayHDR 600：在 500 基础上峰值 600 nit、要求更好对比度与色域；
- DisplayHDR 1000：峰值 1000 nit、对比度翻倍；
- DisplayHDR 400/500 True Black：面向 OLED，黑位低至约 0.0005 nit。
- 强调：600 nit 的显示器不一定能通过 DisplayHDR 600；DisplayHDR 400 认证门槛低（部分人称“废物”），但也不应全盘否定。

**开 HDR 后桌面变灰/变暗的原因**：Windows 桌面只支持 sRGB，无法正确识别广色域内容；HDR 会把低亮度内容进一步压缩，亮度/色域不足的屏会显得惨白灰暗。解决办法：调 HDR/SDR 亮度平衡滑块；根本做法是**平时用 SDR，只在 HDR 游戏/影视时开 HDR**。

**如何测 SDR/HDR 亮度**：可借助家用校色仪（如 Datacolor Spyder X 等，注意需支持测量的型号）。

**PC 播放 HDR 的硬件要求（文中观点，较早期）**：显卡需支持 10bit 输出与 HEVC 硬解；接口用 HDMI 2.0a / DP 1.4；播放软件如 PotPlayer 搭配 madVR。
