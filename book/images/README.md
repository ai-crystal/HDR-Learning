# 图片目录说明

本目录按章节分目录存放插图：

```text
图片/
├── 01/ … 20/      # 每章一个子目录，存放该章的插图（由 code/第NN章/ 的脚本生成）
└── logo/          # 品牌 logo
```

## 插图是怎么来的

各章插图由 `书/code/第NN章/` 下的 Python 脚本生成，统一用 `书/code/common/hdrfig.py` 保证字体、配色、尺寸一致：

```bash
cd 书/code/第07章
D:\DevTools\Anaconda3\python.exe f1_pq_curve.py     # 输出到 图片/07/f1_pq_curve.png
```

## 新增自己的图片

1. 把图片放进对应章节目录，例如 `图片/07/`；
2. 在章节 Markdown（`书/正文/第07章-*.md`）里引用：

   ```markdown
   ![图 7-1　PQ 与 HLG 曲线对比](图片/07/pq曲线.png)
   ```

3. 重新双击 `书/构建PDF.cmd`，图片会按版心宽度自动缩放，方括号里的文字变成图注。

> 公式、曲线类图建议直接用 `code/` 里的脚本生成，保证全书风格统一；照片/截图类可手动放入。
