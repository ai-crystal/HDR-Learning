# 附录 A　术语速查表

> 按主题分组，按拼音/英文首字母大致排列。第一次读不懂某个词时，翻到这里就好。

## 一、基础概念

| 术语 | 一句话解释 |
|---|---|
| HDR（高动态范围） | 高动态范围（High Dynamic Range）；让画面同时拥有更亮的高光与更深的黑位，扩大明暗范围。 |
| SDR（标准动态范围） | 标准动态范围（Standard Dynamic Range）；HDR 之前的常规画面标准，亮度与色域都被限制。 |
| 动态范围 | 画面最亮处与最暗处的比值，可理解为“能同时容纳的明暗跨度”。 |
| 亮度 / 辉度 | luminance；单位 nit（= cd/m²），表示单位面积发出的光强。 |
| 黑位 | black level；屏幕能显示的最暗亮度，越低越好，决定黑场是否干净。 |
| 峰值亮度 | peak luminance；屏幕最亮能到多少 nit，通常在 10% 或 2% 小窗口下测得。 |
| 对比度 | contrast ratio；峰值亮度 ÷ 黑位。原生对比度才是真实值，“动态对比度”多为营销数。 |
| nit | 亮度单位，1 nit = 1 cd/m²（坎德拉每平方米）。 |
| stop（档） | 亮度每翻一倍记作 1 档；用来直观描述动态范围的倍数关系。 |
| 色彩空间 / 色域 | 一台设备能够表示的全部颜色的集合；在色度图上通常是一个三角形。 |

## 二、色彩科学

| 术语 | 一句话解释 |
|---|---|
| CIE 1931 XYZ | 国际照明委员会建立的颜色数学坐标系，是一切色度计算的基础。 |
| 三刺激值 | 用三种原色的量来描述一种颜色，XYZ 就是最常用的一组三刺激值。 |
| 色度图 | 把颜色画成平面地图（马蹄形），是观察色域、白点的通用工具。 |
| 白点 | white point；画面中“白色”的坐标，常见 D65，主流标准都以它为基准。 |
| D65 | 一种标准白光，色温约 6500K，是绝大多数显示标准的参考白点。 |
| sRGB | 1996 年由惠普与微软制定的通用色彩空间，网页与 SDR 的标准。 |
| BT.709 / Rec.709 | 高清电视的标准色域，与 sRGB 基色几乎相同。 |
| DCI-P3 | 数字电影常用色域，比 sRGB 大，苹果的 Display P3 以其为基。 |
| BT.2020 / Rec.2020 | 超高清电视标准，色域很大，是 HDR 常说的“容器”。 |
| 传递函数 | transfer function；描述“码值”与“实际光亮度”之间换算关系的函数。 |
| OETF / EOTF | 光电转换函数（采集用）/ 电光转换函数（显示用），方向相反，不可混用。 |
| Gamma（伽马） | SDR 中著名的非线性曲线（约 2.2），本质是一种亮度编码方式。 |
| BT.1886 | 现代显示设备的参考 EOTF 标准，接近纯 Gamma 2.4。 |
| PQ（ST 2084） | 感知量化（Perceptual Quantizer）；HDR 的绝对式亮度传递函数，0–10000 nit。 |
| HLG | 混合对数伽马（Hybrid Log-Gamma）；HDR 的相对式、兼容 SDR 的传递函数。 |
| BT.2100 | 定义 HDR 电视（PQ 与 HLG 两种方案）的国际标准。 |

## 三、标准与元数据

| 术语 | 一句话解释 |
|---|---|
| HDR10 | 最通用、开放的 HDR 格式：PQ + 10bit + BT.2020 容器 + 静态元数据。 |
| HDR10+ | 在 HDR10 基础上加入逐场景/逐帧动态元数据，免版税。 |
| 杜比视界（Dolby Vision） | 杜比的专有 HDR 格式，动态元数据，可 12bit，用 ICtCp，需授权。 |
| 静态元数据 | 整部片子共用一套亮度信息，简单但不灵活。 |
| 动态元数据 | 每一场景甚至每一帧都可单独给亮度信息，暗场亮场可分别优化。 |
| MaxCLL | 最大内容亮度（Maximum Content Light Level）；整片最亮像素的亮度。 |
| MaxFALL | 最大帧平均亮度（Maximum Frame-Average Light Level）。 |
| ST 2086 | 规定母版显示器基色、白点与亮度的元数据标准。 |
| CTA-861 | 定义 HDMI 传输元数据（含 HDR 静态元数据）的规范。 |
| 位深 / 色深 | bit depth；每个颜色通道用多少位表示，8bit / 10bit / 12bit。 |
| 色带 | banding；位深不足时渐变区域出现的条状断层。 |
| 抖动 / FRC | dithering / 帧率控制；用快速闪变“骗”出更多灰阶，8bit+FRC 并非真 10bit。 |
| 色度采样 | chroma subsampling；对色度信息降采样以省带宽，如 4:4:4 / 4:2:2 / 4:2:0。 |
| YCbCr | 把亮度（Y）与色度（Cb、Cr）分离的编码方式，视频常用。 |
| ICtCp | HDR 更适用的、接近“恒定亮度”的色彩编码，杜比视界采用。 |
| HEVC / VP9 / AV1 | 三种能承载 HDR 的主流视频编解码格式。 |

## 四、硬件

| 术语 | 一句话解释 |
|---|---|
| LCD | 液晶显示器；靠背光发光、液晶“闸门”遮挡来成像，天生黑不下去。 |
| IPS / VA / TN | 三种主流液晶面板类型，对比度、可视角度、响应各有取舍。 |
| 背光 | LCD 的光源；分为侧入式与直下式。 |
| 全局调光 / 局部调光 | 整块背光一起调 / 分成许多区域分别调；后者是 LCD 做 HDR 的关键。 |
| FALD | 全阵列局部调光（Full-Array Local Dimming）。 |
| Mini-LED | 用大量微小 LED 做背光，分区数与峰值亮度都大幅提升。 |
| OLED | 有机发光二极管；每个像素自己发光、可完全熄灭，黑位极致。 |
| WOLED / QD-OLED | OLED 的两条技术路线：白光 + 滤光片 / 蓝光 + 量子点。 |
| ABL | 自动亮度限制（Automatic Brightness Limiter）；OLED 大面积亮场时压低亮度。 |
| 烧屏 | burn-in；OLED 长时间显示同一画面留下的残影。 |
| MicroLED | 微小 LED 自发光阵列，亮度高、无烧屏，但成本高、尚在早期。 |
| 光晕 / 泛光 | blooming；分区调光时亮区“溢出”到邻近暗区的现象。 |
| DisplayHDR | VESA 的显示器硬件认证（≠内容格式），等级从 400 到 1400、True Black。 |
| True Black | DisplayHDR 面向 OLED 的分支，黑位低至约 0.0005 nit。 |

## 五、传输与系统

| 术语 | 一句话解释 |
|---|---|
| 带宽 | bandwidth；接口每秒能传的数据量，单位 Gbps，决定能带多高的分辨率/帧率/色深。 |
| HDMI | 影音设备最常用的接口；2.0 约 18 Gbps，2.1 约 48 Gbps。 |
| DisplayPort（DP） | PC 显示主力接口；1.4 有效约 25.9 Gbps，2.x 最高约 80 Gbps。 |
| USB-C / DP Alt Mode | 椭圆形接口及其“借道 DP 传视频”的模式；能否放 HDR 看它跑的协议。 |
| EDID | 显示器向主机上报自身能力的“自我介绍”。 |
| HDCP | 内容保护机制；播放受保护内容需 HDCP 2.2/2.3，版本不匹配会黑屏或降级。 |
| DSC | 显示流压缩（Display Stream Compression）；约 3:1 的视觉无损压缩。 |
| VRR / ALLM / eARC | 可变刷新率 / 自动低延迟 / 增强音频回传，HDMI 2.1 的新特性。 |
| Auto HDR | Windows 为老 SDR 游戏自动补 HDR 的功能。 |
| HDR 校准应用 | Windows 官方工具，用三张测试图校准最小亮度、最大亮度与最大帧平均亮度。 |
| EDR | 苹果的“扩展动态范围”，在普通界面里局部开 HDR。 |
| HGiG | HDR 游戏兴趣组；主张由游戏端做映射、显示端只做忠实还原。 |

## 六、软件与实战

| 术语 | 一句话解释 |
|---|---|
| 色调映射 | tone mapping；把大范围的内容亮度“折叠”进显示器能力范围的过程。 |
| 色域映射 | gamut mapping；把源色域的颜色映射到目标色域，尽量保持观感。 |
| BT.2390 | 规定 HDR 与 SDR 之间参考映射（EETF）的标准。 |
| EETF | 电光转换函数延伸（Extended Electro-Optical Transfer Function），一种映射方式。 |
| ACES | 一套影视行业通用的色彩管理与映射体系。 |
| madVR / mpv | 常见的发烧级视频渲染/播放方案，支持精细的 HDR 处理。 |
| 3D LUT | 三维查找表；用于精确的色彩转换与校准。 |
| ICC 配置文件 | 描述某设备色彩特性的档案，供系统做色彩管理。 |
| ΔE | 衡量两种颜色差异的指标，数值越小越接近。 |
| UHD 蓝光 | 超高清蓝光，常见 HDR10/杜比视界的实体片源。 |
