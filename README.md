# HDR 技术系列

> 从像素到眼睛，再到色彩科学与工程实现

同一主题按读者目标拆成三册。入门篇把 SDR 的来历、亮度与色域、标准、硬件、接口、系统与实战一次讲通；色彩科学篇与 HDR 技术篇各 12 章，分别深入颜色测量、色貌模型、色域映射、色彩管理，以及传递函数、元数据、色调映射、编码传输与显示实现。

三册共用一套术语与图示风格。入门篇可以顺序通读，两本专业册适合按需查阅。

## 怎么读

- 刚接触 HDR：从入门篇第 1 章开始，把 SDR、亮度、色域与标准串起来。
- 要做色彩管理：读色彩科学篇，重点是 CIE 体系、均匀色彩空间与色域映射。
- 要做显示或编码：读 HDR 技术篇，重点是 PQ / HLG、ST 2094、BT.2390 与面板测量。
