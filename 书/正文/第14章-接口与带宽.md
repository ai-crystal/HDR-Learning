# 第 14 章 接口与带宽：HDMI、DisplayPort 与 USB-C

这一章我们要搞懂一件很实在、却很常被忽略的事：**画面再好，也得有根线能把它搬过去**。你可能买了一台标称 1000 nit 的 HDR 显示器，结果插上配套线一开 HDR 就闪屏、掉到 30Hz，甚至干脆黑屏——问题往往不在屏幕，而在"接口的带宽不够"。本章先给你一个水管的类比，再把 HDMI、DisplayPort、USB-C 这几条主流水管的版本、粗细（带宽）讲清楚，然后教你用一条公式亲手算出"4K60 10bit 要多大水管"，最后提醒你线材认证这件事。

---

## 一、先打个比方：接口像水管，带宽像管径

把数据想成水，接口就是水管，**带宽（bandwidth）就是水管的直径**。分辨率、帧率、色深、色度采样，都是"你这台设备同时要流多少水"。

SDR 时代常年在 "1080p 60Hz 8bit" 这种小流量下跑，一根细管绰绰有余。到了 HDR，画质一下要"同时变多"：

- 分辨率更高（1080p → 4K），像素数变成约 4 倍；
- 帧率更高（60 → 120Hz），每秒要多画一倍；
- 色深更高（8bit → 10bit），每个像素的颜色信息更多；
- 还要额外塞进 HDR 元数据。

结果就是：HDR 高帧率高色深，是"同时要更多水"。**接口带宽不够，画面要么降级（掉色深、掉帧率、加压缩），要么直接断流。** 这也是本篇（传输与系统篇）之所以重要的原因：HDR 从来不是单点的事，而是"内容→显卡→线→接口→屏幕"整条链路要一起达标。

---

## 二、你桌上这些口都是什么来头

### HDMI（High-Definition Multimedia Interface，高清多媒体接口）

影音设备最常见的口，电视、显示器、游戏主机、机顶盒都用它。关键版本：

| 版本 | 大致带宽 | 你能得到什么（直观说法） |
|---|---|---|
| HDMI 1.4 | 约 10.2 Gbps | 4K30 时代的口，HDR 基本无望 |
| HDMI 2.0 / 2.0b | 约 18 Gbps | 4K60 的主流口，HDR10 靠它起步 |
| HDMI 2.1 / 2.1a | 约 48 Gbps | 4K120、8K60、VRR、eARC 等新功能 |

要注意：**型号里带 HDR 字样 ≠ 一定支持 HDR**。真正让 HDMI 能传 HDR10 的是 **HDMI 2.0a 及以上**（它加入了传输静态元数据的能力，见第 8 章、第 15 章）。HDMI 2.1 则是把带宽一口气拉到约 48 Gbps，并顺带带来一堆新特性（VRR、ALLM、eARC，第 15 章细讲）。

### DisplayPort（简称 DP）

PC 显卡和显示器之间的主力口，也是高刷新率、多屏、专业显示的最爱。关键版本：

| 版本 | 大致带宽（原始 / 有效） | 说明 |
|---|---|---|
| DP 1.2 | 约 21.6 / 17.3 Gbps | 4K60 的老口 |
| DP 1.4 | 约 32.4 / 25.9 Gbps | HDR、4K120（配合 DSC）常见 |
| DP 2.0 / 2.1 | 最高约 80 Gbps | 4K高刷、8K、多屏的"大水管" |

这里出现两个数字要留意：**"原始带宽"和"有效带宽"不是一个数**。DP 1.x 用 8b/10b 编码，每传 8 位有效数据要额外搭 2 位（约 25% 开销），所以 DP 1.4 标称 32.4 Gbps，真正能装画面的有效带宽约 25.9 Gbps。买口、选线时看"有效带宽"更实在。

### USB-C 与雷电（Thunderbolt）

USB-C 是那个"正反都能插"的椭圆形接口。它本身只是一种**物理形状**，真正决定能不能传画面的是它跑的"协议模式"：

- **DP Alt Mode（替代模式）**：让 USB-C 借 DP 通道输出视频，是目前笔记本外接显示器最常见的玩法。
- **雷电（Thunderbolt）**：把 PCIe 数据、USB、DP 视频打包在一起的"全能通道"，外接显示、硬盘、扩展坞一根线搞定。

换句话说，**USB-C 能不能放 HDR，取决于它背后接的到底是 DP 1.4、雷电，还是只支持 USB 2.0 的"假视频口"**。买扩展坞和线之前，一定要确认它支持 DP Alt Mode 的哪个版本。

### 退场的老朋友：DVI、VGA

DVI 和 VGA 是上一代接口，VGA 是模拟信号，DVI 带宽和功能都落后，**两者都无缘 HDR**。看到这两个口，基本可以判定这台设备是"老机器"。

## 三、一条公式，算出你要多少带宽

不用背一堆表，你只要记住这条**基础带宽估算公式**：

```text
所需带宽 ≈ 像素总数/秒 × 每像素位数 × 开销因子

其中：
  像素总数/秒 = 横向像素 × 纵向像素 × 帧率
  每像素位数  = 色深 × 通道数 ×（受色度采样影响的折扣）
  开销因子    = 协议编码、空白间隙等额外开销，通常约 1.1 ~ 1.25
```

一句话解释每个符号：

- **横向/纵向像素**：比如 4K 是 3840 × 2160。
- **帧率**：每秒画多少张，60Hz 就是 60。
- **色深 × 通道数**：RGB 三通道，10bit 就是 3 × 10 = 30 位。
- **色度采样折扣**：4:4:4 不折扣；4:2:0 只保留 1/4 的色度信息，相当于每像素省下不少位（见第 10 章）。
- **开销因子**：真实协议里还要编码、留同步间隙，所以实际所需比"纯像素位"要高。

![图 14-3　带宽估算公式的三个因子，以及逐因子放大后的需求增长](图片/14/f3_bw_formula.png)

### 活例子：4K60 10bit 4:4:4 要多少？

```text
像素总数/秒 = 3840 × 2160 × 60 ≈ 4.98 亿像素/秒
纯像素位    = 4.98 亿 × 30 bit ≈ 149 亿 bit/s ≈ 14.9 Gbps
加约 25% 开销 ≈ 18.7 Gbps
```

结论：**4K60 10bit 4:4:4 大约要 18.7 Gbps 的有效带宽**。这个数字，恰好卡在 HDMI 2.0 的 18 Gbps 门槛之上——所以它上不去。

![图 14-4　4K60 10bit 4:4:4 ≈18.7 Gbps 的算例分解](图片/14/f4_4k60_case.png)

## 四、为什么 HDMI 2.0 只能"降一点"

既然 4K60 10bit 4:4:4 要 18.7 Gbps，而 HDMI 2.0 只有 18 Gbps，就得"降一点"才能装下。常见两条路：

| 方案 | 每像素平均位数 | 大致所需 | HDMI 2.0 能上吗 |
|---|---|---|---|
| 4K60 8bit 4:4:4 | 24 bit | 约 14.9 Gbps | ✅ 可以 |
| 4K60 10bit 4:2:0 | 约 15 bit | 约 9.3 Gbps | ✅ 可以 |
| 4K60 10bit 4:4:4 | 30 bit | 约 18.7 Gbps | ❌ 不行 |

也就是说，在 HDMI 2.0 上你要 HDR（10bit），多半得**把色度采样降到 4:2:0**（色彩细节打折），或者**把色深降到 8bit**（牺牲 HDR 的暗部层次）。鱼和熊掌很难兼得。

想"既要 4K60、又要 10bit 4:4:4"，出路有三条：

1. 换 **HDMI 2.1**（约 48 Gbps），带宽富余，一步到位；
2. 用 **DP 1.4**（有效约 25.9 Gbps），已经够跑；
3. 开启 **DSC（Display Stream Compression，显示流压缩）**，把数据视觉无损地压到约 1/3，让有限带宽也能跑高分高刷（第 15 章细讲）。

> 提醒：厂商标的"支持 4K120"背后，可能是靠 DSC 或色度采样换来的。看到高规格，顺手确认一句"是 4:4:4 吗？开 DSC 了吗？"，你就比大多数人懂行。

### 常见组合的"带宽账"（速查表）

下面这张表用上面同一条公式、同一个开销因子（约 1.25）估算，方便你一眼判断"我的口够不够"：

| 组合 | 大致所需带宽 | 谁能上 |
|---|---|---|
| 1080p60 8bit 4:4:4 | 约 3.7 Gbps | 几乎所有接口 |
| 1440p144 8bit 4:4:4 | 约 15.9 Gbps | HDMI 2.0 / DP 1.4 起 |
| 4K60 8bit 4:4:4 | 约 14.9 Gbps | HDMI 2.0 起 |
| 4K60 10bit 4:2:0 | 约 9.3 Gbps | HDMI 2.0 起（HDR 常见档） |
| 4K60 10bit 4:4:4 | 约 18.7 Gbps | HDMI 2.1 / DP 1.4 起 |
| 4K120 10bit 4:4:4 | 约 37 Gbps | HDMI 2.1（常配 DSC）/ DP 2.x |
| 8K60 10bit 4:2:0 | 约 37 Gbps | HDMI 2.1（常配 DSC）/ DP 2.x |

看懂这张表，你就能自己回答很多日常问题：**"我这台老电视插电脑能不能 4K60 HDR？"**——查一下它是 HDMI 2.0 还是 2.1，再对照表格里 HDR 的典型组合（4K60 10bit 4:2:0）是否放得下，答案就出来了。注意表里的数都是**约值**，真实协议、时序开销会有小幅出入，够用就行。

### 为什么很少有 8K 144Hz屏幕

实现8K 144Hz最大的阻碍在于数据传输带宽和硬件性能。
- 接口带宽触顶：当前主流接口（如HDMI 2.1，带宽48Gbps）在无压缩下仅能支持4K 120Hz。要传输8K 144Hz的海量数据，必须依赖显示流压缩（DSC） 技术，但这可能带来轻微的画质损失。即便是更新的接口，要完美驱动8K 144Hz也相当吃力。
- 硬件性能跟不上：即便是顶级的显卡，也很难在8K分辨率下为3A游戏提供稳定的144帧体验。因此，许多厂商认为当前8K的实用价值有限，更倾向于先普及8K 120Hz或探索5K分辨率。

尽管原生8K 144Hz尚未普及，但市场上已有以下极具代表性的产品：
- 8K 120Hz 显示器：这是目前最接近你需求的产品。例如京东方（BOE） 已展示并计划量产31.5英寸8K 120Hz面板，其特色是可切换至4K 240Hz模式，在8K高分辨率与4K超高刷新率间灵活选择。
- 8K 240Hz 超宽屏：三星G95NC是一款57英寸、分辨率达7680×2160（32:9超宽屏）的显示器，刷新率高达240Hz。虽然它的垂直分辨率（2160）与标准8K（4320）有差距，但其总像素量远超4K，可视为一种“准8K”高刷方案。

在10-bit HDR、4:4:4色度采样下，无压缩传输8K 120Hz需要约 119.44 Gbps 的带宽。而目前顶级的HDMI 2.1接口，有效带宽仅约 42.6 Gbps；DisplayPort 2.1（UHBR20）的有效带宽也“仅”为 77.4 Gbps，都远不能满足要求。因此，必须开启DSC。DSC是一种视觉无损的压缩技术，压缩比可达3:1左右，能将数据量大幅降低，从而让8K 120Hz的信号能够通过现有接口传输。有分析指出，即使是“残血版”的DP 2.1接口，在开启DSC后也能实现8K 120Hz输出。


### 带宽不够时，系统会怎么"降级"？

很多设备不会直接拒绝你，而是**悄悄降级**，顺序通常是：

```text
先保分辨率与帧率
  ↓ 带宽还紧张？
降色度采样（4:4:4 → 4:2:2 → 4:2:0）
  ↓ 还紧张？
降色深（10bit → 8bit）
  ↓ 还紧张？
降刷新率或分辨率
  ↓ 最后的办法
开 DSC 压缩
```

这就是为什么你"看起来没动任何设置"，HDR 却莫名变成 8bit 或 4:2:0——其实是链路在带宽压力下自动做了取舍。想知道自己实际跑在什么档位，可以在显卡控制面板或显示器信息页里查看**当前实际输出格式（分辨率/刷新率/色深/色度采样）**，别只看包装盒宣传。

## 五、线材认证：别拿旧线当新线

水管口径再好，**线本身也必须是那根粗管**。这就是所谓"高带宽认证线"的意义：

- **HDMI Ultra High Speed（超高速）**：对应 HDMI 2.1 的高带宽能力，认证线才能稳跑 48 Gbps 级别的规格。
- **DP 认证（如 DP80）**：对应 DP 2.x 的高带宽档位。

关键提醒：**旧线不等于新线**。HDMI 2.0 那代的线，插到 HDMI 2.1 口上，带宽上限依然是旧的，很容易出现"接口明明支持 4K120，实际只能 60Hz 甚至闪屏"。遇到"接口标得很高、实际跑不满"，第一件事就是换一根认证过的高带宽线试试。线不宜太长（通常 2 米以内更稳），劣质长线是 HDR 掉线的常见元凶。

## 六、选线选口的实操清单

把前面的知识变成一张能照着做的清单：

1. **先定目标**：写清楚你要的"分辨率 + 刷新率 + 色深 + 色度采样"（例如 4K120 10bit 4:4:4）。
2. **再查带宽**：用公式或速查表估个所需带宽，留一点余量。
3. **对接口版本**：HDMI 2.0（约 18 Gbps）/ 2.1（约 48 Gbps）；DP 1.4（有效约 25.9 Gbps）/ 2.x（最高约 80 Gbps）。
4. **配认证线**：HDMI 用 Ultra High Speed 认证线，DP 用对应高带宽认证线，长度控制在 2 米以内更稳。
5. **直连优先**：能直连就直连，中间少接切换器、老功放、廉价转接头。
6. **验货再收工**：开起来后查实际输出格式，确认真的跑在你想要的档位上，而不是被悄悄降级。

记住一句话：**接口负责"水管够不够粗"，但真正决定体验的是"内容+线+口+屏幕+设置"整条链路一起合格。** 本章管的是前几环；后面几章把系统、映射和内容补齐。

## 本章小结

- 接口是水管，**带宽是管径**；HDR 高帧率、高色深是"同时要更多水"。
- 主流版本带宽：HDMI 2.0 约 18 Gbps、HDMI 2.1 约 48 Gbps；DP 1.4 原始约 32.4 Gbps、有效约 25.9 Gbps；DP 2.x 最高约 80 Gbps。
- 一条估算公式：**像素总数/秒 × 每像素位数 × 开销因子**；4K60 10bit 4:4:4 约需 18.7 Gbps，所以 HDMI 2.0 只能选"8bit 4:4:4"或"10bit 4:2:0"。
- USB-C 只是形状，**能不能放 HDR 看它跑的协议**（DP Alt Mode / 雷电）。
- 高带宽必须配**认证线**；旧线、劣质长线是最常见的 HDR 掉链子点。

## 常见误区与自测

1. **误区：接口标了 HDR 就一定支持 HDR。** 实际上要 HDMI 2.0a 以上、且链路和你设的分辨率/帧率/色深组合真的放得下，才算数。
2. **误区：拿旧 HDMI 线插 HDMI 2.1 口就能跑满。** 线的带宽上限不会因为你换了大口而提升。
3. **误区：看到"4K120"就以为是无条件原生。** 很可能是靠 DSC 或 4:2:0 换来的，画质上仍各有取舍。
4. **自测：** 你的线是几米的、有认证吗？如果开 HDR 后只能 4K60 8bit，你能说出两种"想要 10bit 该怎么办"的方案吗？（提示：换 DP/HDMI 2.1、开 DSC、或降色度采样。）
