# 全书图示规格（各章绘图子任务共用）

> 目标：为《HDR 超详解》20 章配齐丰富、风格统一的图示。**图示要尽可能多、信息量足、直观好看。**

## 一、通用规范（务必遵守）

### 1. 环境与工具
- 绘图解释器：`D:\DevTools\Anaconda3\python.exe`（含 matplotlib / numpy / PIL / scipy）。
- 需要 OpenGL/3D 或 torch 时：`D:\DevTools\Anaconda3\envs\moge3\python.exe`（含 `moderngl`，可 `moderngl.create_standalone_context()` 离屏渲染）。
- 通用工具模块：`E:/Study/HDR-Learning/书/code/common/hdrfig.py`，**每个脚本开头必须**：
  ```python
  import sys; sys.path.insert(0, "E:/Study/HDR-Learning/书/code/common")
  import hdrfig as H
  ```
  它已配置好中文字体、配色常量与 HDR 数学函数（`H.pq_eotf/pq_oetf/hlg_oetf/hlg_eotf/srgb_eotf/gamma_*` 等）。

### 2. 代码存放
- 每章代码放在 `E:/Study/HDR-Learning/书/code/第NN章/`（NN 为两位章号，如 `第07章`）。
- 建议每个脚本对应一张或一组相关图，文件名如 `f1_pq_curve.py`。脚本必须可独立运行（`python f1_xxx.py`）。

### 3. 图片输出
- 输出到 `E:/Study/HDR-Learning/书/图片/NN/`（NN 为两位章号，由 `H.save(fig, NN, "f1_xxx")` 自动定位）。
- 命名：`f<序号>_<英文短名>.png`（如 `f1_pq_curve.png`、`f3_gamut_compare.png`）。
- 用 `H.save(fig, NN, "f1_xxx")` 保存（自动 150 dpi、白底、紧凑裁剪）。

### 4. 版式与风格
- 画布宽度约 `figsize=(7.2, h)`（英寸），h 视内容 3–5.5；保证在书页里清晰。
- 标题用中文、加粗；轴标签中文；必要时加图例。
- 配色统一使用 `H.` 里的常量（`H.NAVY / H.ORANGE / H.TEAL / H.RED / H.PURPLE / H.GREEN / H.BLUE / H.GOLD / H.GRAY`）。
- 少用花哨背景；白底、浅灰网格。暗色场景对比图可用深色面板表示"暗场"。
- 数值标注清楚单位（nit、nm、Gbps、bit、%）。曲线图尽量标关键点。
- **信息量优先**：一张图能表达多层信息就尽量表达（多条曲线、双轴、分区标注、注释文字）。

### 5. 在正文中插入图片
- 在章节 Markdown（`E:/Study/HDR-Learning/书/正文/第NN章-*.md`）中，把每张图插入到**内容相关的小节末尾**，单独一行：
  ```markdown
  ![图 NN-k　图题](图片/NN/fk_slug.png)
  ```
  其中 `NN-k` 的 k 与文件名 `fk_` 对应；图题用中文简述该图在看什么。
- 不要改动正文其它文字；不要动本章小结/常见误区/下一章预告的原有内容（图可放在它们之前）。
- 路径以 `图片/` 开头（构建时会自动解析到 `书/图片/`）。

### 6. 自检
- 生成后确认每个 PNG 文件存在且大小 > 8 KB；脚本不得报错。
- 可用同一解释器再次运行脚本验证可复现。
