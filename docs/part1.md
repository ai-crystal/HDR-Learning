# 第一篇　基础篇：为什么会有 HDR

> “我们不是在给屏幕加参数，而是在把被压扁了几十年的画面，一点一点撑回它本来的样子。”

要理解 HDR，先得理解它的对手——SDR。今天绝大多数我们习以为常的画面，都活在一个被“约定”钉死的小盒子里：亮度锁在约 100 nit 附近，色域锁在 sRGB 的一小块三角形里。这不是技术懒惰，而是历史与成本共同写下的规矩。

这一篇先带你回到那个盒子的起点，看清它的来龙去脉；再把“亮度、对比度、动态范围”这几个最常被含糊带过的词讲清楚；最后回答一个最根本的问题——人眼为什么会“需要”，也“配得上”HDR。

读完这一篇，你会明白：HDR 不是让画面“更亮更艳”，而是让画面重新接近我们真实看到的世界。
