# HDR 超详解

> 从像素到眼睛的完整指南 · 作者：Dezeming

本书用最直白的方式讲清**高动态范围（HDR）**：从光与颜色的基础，到色域与传递函数，到 HDR10、杜比视界、HDR10+ 与 HLG 的规则，再到面板、接口、操作系统、播放软件与调色，最后落到选购、校准与排查。

- **6 篇 20 章**，配 90 余张原创示意图
- 可从左上角目录逐章阅读，也可 [**下载整本 PDF**](HDR超详解.pdf)
